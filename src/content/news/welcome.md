Trinity Games is an index of decompilations, recompilations and PC ports of classic games. We link to each project's own page and never host games, ROMs or downloads.

Project data such as the latest release and last activity refreshes automatically every day from GitHub. Every entry is reviewed by hand before it appears.

You can suggest a project or report a mistake through the links in the sidebar.
